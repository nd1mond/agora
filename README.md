# 🎓 Agora — Платформа обмена учебными материалами
Agora — это веб-платформа для студентов, предназначенная для централизованного хранения, обмена и интеллектуальной обработки учебных материалов (лекций, шпаргалок, методичек).

Проект разработан с использованием FastAPI, PostgreSQL и интегрирован с нейросетевой моделью GigaChat для автоматической генерации краткого содержания (саммари) документов.

## 🚀 Основной функционал
Аутентификация: Регистрация с подтверждением по Email, безопасный вход, восстановление пароля.

Файловое хранилище: Мульти-загрузка файлов (.pdf, .docx, .txt) с привязкой к предметам и курсам.

AI-Аналитика: Автоматическое извлечение текста из файлов и генерация саммари через GigaChat API.

Планировщик задач: Личный Task Manager с дедлайнами и приоритетами.

Социальные функции: Лайки, избранное, счетчики просмотров и скачиваний.

Профили: Настройка публичности профиля, аватарки, информация о ВУЗе.

## Технологический стек
Язык: Python 3.10+

Бэкенд фреймворк: FastAPI

База данных: PostgreSQL

ORM: SQLAlchemy

Шаблонизатор: Jinja2 (Server-Side Rendering)

AI: GigaChat SDK

Безопасность: BCrypt (хеширование паролей)
